## 📌 Descripción del Proyecto
Este proyecto contiene la resolución de la "Entrega Previa 1" correspondiente a la Semana 3 del módulo de Estructuras de Datos. El objetivo principal es aplicar los conceptos de estructuras de datos lineales (específicamente arreglos unidimensionales) para modelar y resolver situaciones problemáticas, validando restricciones, analizando el manejo de memoria y aplicando buenas prácticas del paradigma Orientado a Objetos (POO).

## 📂 Estructura de los Archivos
El proyecto está dividido en un componente práctico (código fuente) y un componente teórico (documentación):

*   `Ejercicio1.java`: Algoritmo para encontrar la intersección entre dos arreglos de números enteros ingresados por el usuario.
*   `Ejercicio2.java`: Algoritmo optimizado con complejidad O(n) que identifica el segundo número más grande dentro de un arreglo de 10 posiciones.
*   `Ejercicio3.java`: Algoritmo que evalúa un arreglo de cadenas de texto (Strings) para encontrar la palabra más larga y retornar su índice.
*   `Respuestas_Teoricas.docx`: Documento con la investigación sobre el diseño de clases y la comparativa entre los componentes de la POO y el paradigma procedural.

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java (JDK 8 o superior).
*   **Entrada de datos:** `java.util.Scanner` con manejo estricto de excepciones (`InputMismatchException`, `NumberFormatException`).
*   **Paradigma:** Programación Orientada a Objetos (POO).

## 🚀 Cómo ejecutar los programas
1. Asegúrate de tener el Java Development Kit (JDK) instalado en tu sistema.
2. Abre una terminal o consola de comandos.
3. Navega hasta el directorio donde se encuentran los archivos `.java`.
4. Compila el archivo deseado usando el comando: `javac NombreDelArchivo.java` (ej. `javac Ejercicio1.java`).
5. Ejecuta el programa compilado con el comando: `java NombreDelArchivo` (ej. `java Ejercicio1`).
6. Sigue las instrucciones impresas en la consola para ingresar los datos requeridos.
